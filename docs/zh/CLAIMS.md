## ❌ 负结果（如实报告，不埋没）

- **推理绑定注入不被语义利用**（W103，真实 UCI 风控）：H 与 Hwrong（投毒）答案 64/64 逐字相同——
  注入只扰乱生成轨迹、与内容无关。文本态历史（P）有效；原生 K/V 注入在此任务无效。
- **Fixation**（W93）：注入可致重复固化；需驱逐（定时/读出）。注意力门控无效（fixation 即持续注意）。
- **注入幅度放大失败**（W111）：scale=2.0 退化（乱码＋复读）且倒退正确答案；放大注入不能干净压过 prior。
- **强制注入无关事实会污染**（W110）：无阈值门控时，无关答案被记忆实体/措辞污染。必须阈值门控。
- **残余约 12 点 prior 抵抗**（W109/W111）：覆盖＋自然句后，4B 冲突（0.80）仍落后干净（0.92）；
  底座越大越抵抗反事实注入。对 scale 顽固；疑为容量/融合权衡。
- **更大底座≠冲突更好**（W106）：4B prior 强于 0.8B→覆盖前更抵抗；容量助抗稀释，不助反事实接受。

## 基准数字（机制级，MAB 真实数据，MIT）

4B，自然句编码＋覆盖，ent_mean top-1，CPU：
- 干净召回（n=25）：**0.92**（模板 0.84）
- 冲突（n=40）：**0.80**（模板 0.55；只追加 0.35）

0.8B，自然句编码＋覆盖，ent_mean top-1，CPU（经 `benchmarks/mab/run.py` 复现）：
- 干净召回（n=25）：**0.92**（模板＋覆盖曾为 0.88）
- 冲突（n=40）：**0.825**

**臂对照，MAB 干净（0.8B，自然句，n=15）：** N 0.20 / H 原生 **0.933** / RAG 文本 **1.00** / P 文本 **1.00**。
→ 小干净单跳事实集上，**文本与原生注入一样好或略好**；原生有竞争力但此场景不胜文本。
原生优势在选择性/可写/省上下文，不在此场景。

**Mem-PAL 推理绑定（自然句，16 题 6 用户，GPU，实测）：**

| 臂 | 0.8B | 4B |
|---|---|---|
| N 无记忆 | 0.421 | 0.451 |
| P 全文本 | 0.462 | 0.469 |
| RAG 检索文本 | **0.506** | 0.438 |
| H 原生单发 | 0.372 | **0.480** |
| H 两段式读出→推理 | 0.393 | 0.448 |

**诚实解读：** 4B 上**没有记忆臂显著超无记忆**（最好 +0.029，标准误 0.053）——这 16 题判别力弱
（N 单独 0.45）。单题验证的两段式**两种规模都没赢文本**，那个 n=1 推断已被实测**否证**。
仅方向性（不显著）：原生注入随容量变好（+0.107）、文本 RAG 变差（−0.068），
与"记忆收益=任务类型×底座容量"一致。证据：`results/mempal/`。

限制：MAB sh_6k 单跳；n=40/25/15；substring_exact_match；冲突集 70% 为冲突组。
选择性场景优势（催收 H>P）为**模板时代初步**，待自然句重验。
